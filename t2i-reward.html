复杂文字场景评测

T2I 文字生成的检测、局部评估、全局汇总与奖励函数方案

评测框图

主要技术组件与引用（核对日期：2026-08-22）
  • Prompt Parser / VQA：Qwen3.8 官方仓库列出的开放模型是 Qwen3.8-27B 与 Qwen3.8-2.4T-A95B。Qwen3.8 是统一视觉—语言模型，不使用 Qwen3.8-VL 或 Qwen3.8-Text-Encoder 作为官方模型名。
  • Text Detector / OCR：生产默认采用 PP-OCRv6 Text Detection；曲线文字研究分支采用 EdgeText (2025)；像素级检测对照采用 KAC, CVPR 2024。
  • 层级 Layout：LayoutFormer, CVPR 2024 与 Text Grouping Adapter, CVPR 2024。
  • 历史对照：DBNet, AAAI 2020、DeepSolo, CVPR 2023、DPText-DETR, AAAI 2023。后二者不是“近两年”工作，因此不再作为新版默认推荐。
对 text_validation2.html 的事实修正：Qwen3.8-72B、Qwen3.8-Text-Encoder、Qwen3.8-VL 均不是当前官方模型名；其 Qwen 链接指向旧仓库。另一个错误是把 DocLayout-YOLO 标成“CVPR 2024”：官方仓库给出的引用是 arXiv:2410.12628，且它面向文档版面分析，不适合作为自然场景文字 Layout 的默认模型。

四个评估维度

四个维度按上下顺序展开。每个维度都明确输入、计算方法和输出，避免只给模型名称而没有可执行细节。

01

字形渲染与质量评估

判断笔画是否清楚、完整、连贯；不负责判断内容是否为目标文字。

建议权重 25%
输入
每个文字实例的 crop、text mask、2× 放大图和外围背景环带。对视觉评分器隐藏原始 Prompt 与目标字符串。
底层方法
  • Edge clarity：在 mask 边界带上计算梯度强度、Laplacian 方差和重影比例。
  • Stroke integrity：对二值 mask 骨架化，统计异常断点、局部缺口、短小伪分支和粘连区域。
  • Foreground contrast：比较文字内部与外侧背景环带的 Lab 明度/色度距离。
  • Blind visual judge：Qwen3.8-27B 只看 crop，按固定 rubric 返回 blur / broken / merged / extra-stroke；不得看到目标文本。
局部计算
G_i = 0.30·sharp_i + 0.30·stroke_i + 0.20·contrast_i + 0.20·topology_i每项先在“语言 × 字高 × 透视角”桶内校准到 [0,100]。图像级 D1 采用文字像素面积加权平均，但单个必需实例不得因面积小而被忽略。
输出
{glyph_score, defect_type, severity, char_region, confidence}
注意
OCR confidence 只能作为辅助证据，不能直接等同字形质量；否则“内容易猜但笔画已坏”的文字会被错误给高分。
02

文本内容对齐度评估

目标文本先从用户 Prompt 中抽取；生成图只负责提供观测，不允许反向定义 ground truth。

建议权重 45%
正确顺序
  1. Qwen3.8-27B 从 Prompt 抽取目标实例：content / carrier / region / style / order。
  2. Text Detector 对 T2I 结果切出每个文字片段；OCR 对每个 crop 独立识别。
  3. 将目标实例与 crop 做一对一匹配，而不是把整图 OCR 拼成一个长字符串。
  4. 先计算局部错字、漏字、多字和顺序错误，再汇总为 global score。
结论：不是“Prompt 抽取”和“局部 crop 计算”二选一。Prompt 提供目标文本，crop 提供观测文本；二者匹配后先局部、再全局。
实例匹配
对目标 t_j 与候选 o_i 构造成本：cost(i,j) = 0.60·CER(o_i,t_j) + 0.20·region_mismatch + 0.20·carrier_mismatch通过 Hungarian assignment 得到匹配；未匹配目标记 missing，未匹配候选记 extra text。载体与区域约束仅在 Prompt 明确给出时启用。
局部与全局
local_char_i = max(0, 1 − (S_i + D_i + I_i) / N_i)D2 = 100·(0.50·micro_char_acc + 0.30·exact_instance_rate + 0.20·instance_F1) − P_extramicro_char_acc 按字符总量统计；exact_instance_rate 防止长文本掩盖短标题错误；instance_F1 处理整段缺失和额外文字。
归一化
默认按 Unicode grapheme cluster 对齐。仅忽略 Prompt 允许的空格/换行；数字、大小写、标点和专有名词默认严格匹配。
输出
{target_id, crop_id, ocr_nbest, S/D/I, error_spans, missing, extra, content_score}
03

Layout 与样式一致性评估

硬约束用几何和颜色直接计算；只有“复古、手写、浮雕”等软风格才交给视觉模型。

建议权重 15%
Layout 来源
检测结果使用 LayoutFormer（CVPR 2024） 的 word / line / paragraph 层级思想；若已有检测器，可参考 Text Grouping Adapter（CVPR 2024） 做行与段落分组。
几何计算
  • 将 polygon 坐标除以图像宽高，得到归一化位置、大小和行基线。
  • “中央/上方/下方”等区域约束按 centroid 与预设区域计算命中率。
  • “A 在 B 上方”用相对中心坐标和最小间隔判断；阅读顺序用 Kendall-τ。
  • 标题/副标题层级用字高比、面积比和对齐误差计算，不要求固定像素坐标。
颜色计算
不直接使用整张 crop 的 Color Histogram。先将 text mask 向内腐蚀 1–2 px，取文字前景像素的 Lab 中位数；再与 Prompt 中显式颜色对应的校准色域比较。S_color = exp(−ΔE00(median_Lab(text), target_Lab) / τ_color)对渐变/多色文字，将前景像素聚成最多 3 个 Lab 色簇，再用 Earth Mover's Distance 比较色彩分布。背景像素不得混入文字颜色统计。
风格计算
  • 有参考图：使用 Qwen3-VL-Embedding 比较“文字 crop ↔ 参考文字 crop”，只作为相对相似度。
  • 无参考图：Qwen3.8-27B 按固定 rubric 判定 serif / sans / handwriting / embossed / neon 等离散属性。
  • 不建议用原始 CLIP cosine 直接当绝对分数，因为内容语义、背景和文字风格会混入同一 embedding。
汇总
D3 = 0.45·geometry + 0.20·reading_order + 0.20·color + 0.15·stylePrompt 未指定的颜色、字体或绝对位置不参与扣分。
输出
{constraint_id, expected, measured, tolerance, pass, layout_score}
04

场景语义与逻辑融合评估

评估文字是否真正附着在指定载体上，并符合载体平面、透视、遮挡、光照和材质逻辑。

建议权重 15%
模型选择
默认使用 Qwen3.8-27B 的统一视觉语言能力，输入整图、文字 polygon、载体 crop 和 target spec。Qwen3.8-2.4T-A95B 仅用于少量难例的离线复核。
载体定位
先让模型根据 carrier 返回载体 bbox/polygon，再计算文字区域是否落在载体内部：S_carrier = area(text_polygon ∩ carrier_polygon) / area(text_polygon)对“路牌上、杯身上、墙面上”这类约束，载体未定位成功时不允许仅凭整图语义给高分。
透视与遮挡
对近似平面载体拟合四边形或 homography，比较文字上下基线与载体消失方向；用归一化重投影残差得到 S_perspective。再检查文字与载体前景的遮挡顺序，避免文字漂浮在遮挡物上方。
光照与材质
在文字边缘内外采样局部亮度、色温、噪声与纹理频谱；判断文字是否共享载体的阴影、反光、印刷磨损或曲面变形。确定性统计与 Qwen3.8 rubric 各占一半。
VQA 例 1
路牌载体问题

“目标文字实例 t3 应印在道路标牌上。请返回：①标牌 bbox；②文字 polygon 是否完全位于标牌平面内；③文字基线是否与标牌透视方向一致。只输出 JSON，并给出 evidence coordinates。”

VQA 例 2
材质与光照问题

“观察文字 crop 及其扩大 2× 的载体区域。文字是否共享载体的照明、反射和表面纹理？分别按 0/1/2 评分，并指出导致扣分的局部坐标；不要判断文字拼写。”

交叉推理
问题由 target spec 的 carrier / relation 字段模板化生成，不让模型自由发散。每题以整图和局部载体 crop 各问一次；答案不一致时降低 confidence 或送入大模型复核，而不是简单平均。
汇总
D4 = 0.35·carrier + 0.25·perspective + 0.20·lighting_material + 0.20·VQA_consistency
输出
{carrier_bbox, inside_ratio, reprojection_error, occlusion, lighting, evidence, scene_score, confidence}

总分计算

基础权重与覆盖率门控

S_raw = 0.25·D1 + 0.45·D2 + 0.15·D3 + 0.15·D4 g_cov = √(instance_F1 · char_recall) S_total = clip(g_cov · S_raw − P_extra − P_illegal, 0, 100)

D1–D4 均为 [0,100]。覆盖率采用乘法门控，避免文字缺失后仍靠布局和场景获得高分。权重是 MVP 起点，后续应在人工标注集上拟合。

D1 字形
25%
D2 内容
45%
D3 Layout
15%
D4 场景
15%

硬规则

  • 全部目标实例 exact match = 0：总分上限 35。
  • 任一 required 实例完全缺失：总分上限 55；所有文字缺失：上限 20。
  • 未匹配额外文字按面积和字符数罚分，防止模型重复书写目标词。
  • OCR/VQA 分歧超过校准阈值：输出 abstain，不作为在线 RL 奖励。
  • 训练使用按语言、字数、最小字高和透视角分桶后的稳健归一化分；评测保留原始总分。

两个 Case 的四维规则走查

以下图片由图像生成模型构建。分数是按照上面的规则进行的人工 dry-run，用于检查指标方向和局部/全局汇总是否合理，不冒充已部署评测器的自动跑分。

Case A：三处文字均正确

正例 / 中英混排 / 海报 + 路牌载体

目标：中央金色“未来已来”；下方“2026 AI 峰会”；背景路牌“NO PARKING”。

维度局部证据与结果分数
D1 字形三处边缘清楚，无明显断裂/粘连；小号路牌文字略低于海报清晰度。94
D2 内容3/3 实例 exact match；字符级 S/D/I 均为 0；无额外文字。100
D3 Layout标题居中、副标题位于下方；金色标题与层级比满足 Prompt。93
D4 场景“NO PARKING”位于路牌平面内；海报与路牌透视、照明关系基本合理。91
coverage gate = 1.00096.1 / 100

计算：0.25×94 + 0.45×100 + 0.15×93 + 0.15×91 = 96.1。

Case B：漏字 + 局部笔画粘连

受控反例 / 仅改变文字缺陷 / 布局和场景保持不变

目标不变：图像仅注入“未”字局部粘连，以及 NO PARKING 缺少字母 I。

维度局部证据与结果分数
D1 字形t1 的“未”出现局部笔画粘连；其他区域清晰度基本不变。74
D2 内容t3 OCR = “NO PARKNG”；局部 D=1，CER=1/9；实例 exact match 由 3/3 降为 2/3。89
D3 Layout三个实例位置、层级、颜色均未改变，因此不应随内容错误同步大幅下降。93
D4 场景文字仍附着在原路牌/海报上，透视与光照未改变。91
coverage gate ≈ 0.97684.0 / 100

原始加权分约 86.2；字符召回下降后经 coverage gate 得到约 84.0。D1/D2 定向下降，而 D3/D4 基本稳定，符合四维解耦目标。

下一步真实验证应将这类单因素编辑扩展为 blur、stroke break、substitution、deletion、position shift、wrong carrier、perspective mismatch 等受控对照集，并与人工四维标注计算 Spearman 相关性和 pairwise accuracy。
